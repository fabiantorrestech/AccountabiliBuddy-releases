# AccountabiliBuddy releases

Installers and update packages for **AccountabiliBuddy**, a Windows focus guardian. This repository holds release files only; the source code is private.

## Install

1. Open the [latest release](https://github.com/fabiantorrestech/AccountabiliBuddy-releases/releases/latest).
2. Download `AccountabiliBuddyApp-win-Setup.exe` and run it.

It installs to `%LocalAppData%\AccountabiliBuddyApp` and keeps your data in `%LocalAppData%\AccountabiliBuddy`; everything stays on your computer.

## Updates

The installed app checks this repository for new versions (Settings → Updates). By default it tells you when one is ready and installs when you choose; you can turn on automatic updates there. It never installs during a focus session.
